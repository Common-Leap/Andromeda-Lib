# Andromeda-Lib for JellyCar

A Nintendo Switch only fork of [DrakonPL/Andromeda-Lib](https://github.com/DrakonPL/Andromeda-Lib), updated for current `libnx`. It is the engine used by [JellyCar-NX](https://github.com/Common-Leap/JellyCar-NX), which compiles it from source as part of its own build.

For the other platforms, use the original project.
